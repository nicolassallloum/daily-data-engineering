# Daily Data Engineering

Automated engineering knowledge repository covering:

- PostgreSQL
- SQL
- Oracle
- Snowflake
- Python
- Apache Kafka
- Apache Airflow
- dbt
- Data Architecture
- Data Modeling
- Data Governance
- Data Engineering
- Database Performance

## Purpose

Build and maintain a continuously growing engineering knowledge base.

## Structure

daily/YYYY/MM/DD/

Each generated entry contains:

- Topic
- Engineering focus
- Practice task
- Key technical point

## Automation

GitHub Actions runs the contribution engine every day.

The engine generates between 5 and 10 engineering knowledge entries.

## Technology
